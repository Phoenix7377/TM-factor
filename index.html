What is TM Factor?

Every decision costs both money and time. TM Factor converts both into one single number so you can judge the true cost of a choice.

  • Hours Mode: Combines the work-hours needed to pay for the item plus the hours spent doing it.
  • Minutes Mode: Divides the result by 60 to scale down quick, everyday decisions.

Install on Other Devices

No app store needed. Open this link in any device's browser:

  • Android (Chrome): Tap ⋮ (top right) → Add to Home screen.
  • iPhone / iPad (Safari): Tap the Share icon (bottom bar) → Add to Home Screen.
  • PC / Mac (Chrome or Edge): Click the Install icon inside the right side of the address bar.
